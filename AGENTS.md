# tech-fluency

A self-directed tech literacy course — Python, AI fundamentals, and the six-gate framework for understanding how technology is built.

## Where Things Live

| File / folder | What's in it |
|---|---|
| `README.md` | Public-facing course description and curriculum overview |
| `PROGRESS.md` | Current lesson status and what's been completed |
| `LEARNING-JOURNAL.md` | Amanda's reflections and notes across lessons |
| `LESSON-PROTOCOL.md` | How lessons are structured and run |
| `teaching-framework.md` | Pedagogical approach |
| `curriculum-brief_NEW.md` | Revised curriculum plan |
| `lessons/` | Individual lesson records |
| `field-guide/` | Concept cheat sheets for real-world recognition |

## Local Rules

- This is a public repo. Don't commit personal context or private notes.
- Read `PROGRESS.md` first to understand where the course is up to before working on any lesson.
- Lesson structure is documented in `LESSON-PROTOCOL.md` — follow it when adding new lessons.
